## Selected projects

### [LabLink — Laboratory Specimen Tracking](https://github.com/richarich-92/Lablink-sample-Tracking)

A full-stack specimen-tracking and result-coordination platform concept for managing sample workflows, status updates, role-based access, and operational follow-ups.

**Stack:** React · TypeScript · Node.js · Express · SQLite  
[View source code and setup instructions →](https://github.com/richarich-92/Lablink-sample-Tracking)

### [CRITS Online Shop](https://github.com/richarich-92/CRITS-Online-Shop)

A business storefront for browsing technology products and real-estate listings and sending customer enquiries. The current version is enquiry-based; it does not claim to offer completed online checkout or payment processing.

**Stack:** TypeScript · PostgreSQL · Docker  
[View source code and setup instructions →](https://github.com/richarich-92/CRITS-Online-Shop)

### SnapTrace — AI-Assisted Lost & Found

A project in development exploring how image-based matching can help connect reports of lost and found items. The frontend and backend repositories are currently private.

### Fleet & Facilities Management

An information-system project focused on organising fleet and facilities workflows. It remains under development and should not be treated as production-ready without further security and operational review.
